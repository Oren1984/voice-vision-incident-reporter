## Answer to the research question

> **RQ1 — does text + image beat the best single source on the same examples?** **Not reliably.** On the 955 official test pairs, the combined model reaches Macro F1 **0.816**, image only **0.787**, text only **0.743**. The gain over the best single source (image) is +0.029 with a 95% paired-bootstrap CI of [-0.044, +0.093], which includes 0 — the pre-registered success criterion is **not met** (verdict: *NO RELIABLE IMPROVEMENT: point estimate > 0 but 95% CI includes 0*). Combining **does** reliably beat text alone (+0.073 [+0.011, +0.143]).

What this means for the application: the combined view is at least as good as either source and clearly better than the text alone, so it is used for the category *proposal* — but it is not strong enough to overrule a person, and when the text-only and image-only views disagree (191 of 955 test pairs) the combined view is right only 62.8% of the time (vs 93.7% when they agree). That is why disagreement is surfaced to the reviewer.

## Data

CrisisMMD v2.0, official agreed-label humanitarian split. Train 6,126 / dev 998 / test 955 pairs; no missing or unreadable images (0 / 0). Test class counts: affected 9, infrastructure 81, not_hum. 504, other_rel. 235, rescue 126.

Leakage checks (test vs train): tweet-id overlap 0, image-path overlap 0, normalised-text duplicates 1, near-duplicate images 208 (average hash, Hamming ≤ 4). Details: [dataset.md](dataset.md).

## S3 — paper-inspired fusion head

GuidedDiffAttnHead (ours): guided gating + differential attention over [image, text] tokens, frozen CLIP ViT-B/32 inputs; 396,869 parameters. Test Macro F1 per seed: 13: 0.805 (17 epochs), 42: 0.805 (29 epochs), 7: 0.793 (15 epochs). Mean 0.801 ± 0.007, i.e. -0.015 vs the primary combined model. Additionally computed (not pre-registered): the 3-seed probability ensemble reaches 0.830; vs best single source +0.042 [-0.031, +0.108], vs primary combined +0.014 [-0.014, +0.041] — neither CI excludes 0. The attention-based head does not change the answer to RQ1 in this setting.

## Post-hoc exploratory checks (not pre-registered)

Added after seeing the results, because the combined model's advantage rests partly on the 9-example class and because dev selection gave only the combined model balanced class weights.

- **Without `affected_individuals` (4-class Macro F1):** text 0.795, image 0.859, combined 0.870 → combined − best +0.011. Most of the gap over image comes from the tiny class.
- **All views with balanced class weights** (C re-selected on dev: {'text': 3, 'image': 10, 'combined': 100}): text 0.680, image 0.752, combined 0.816; combined − best +0.064 [+0.002, +0.125]. The margin widens because balanced weighting hurts the single-source models, not because the combined model improves.

Reading: fusion's benefit over the image alone is small and sensitive to class weighting and to a handful of rare-class examples.
